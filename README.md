One-line robot-vacuum alibi entry for the make.fun bounty **"The Vacuum's Alibi: One Line, 200 Characters"**.

`main.py` writes a single one-line excuse from a robot vacuum explaining why it missed a spot to `/output/entry.txt` — 112 characters, one line, deadpan machine voice with the punch at the end.

> My lidar classified that crumb as load-bearing, so I vacuumed around it — I clean houses, I don't demolish them.
